碎境勇者

Shattered Realm — 三维像素 / 动作冒险 / 大陆探索

PC · 手柄优先 单机 · 12–15 小时 低分辨率 3D 渲染 1 人小队可做的规模

01一句话与三根支柱

一个只有两个脑袋高的体素勇者，在一片不断碎裂的悬空大陆上，用三种武器形态和一次完美弹反，把怪物的破防条撬开。

PILLAR 01
读招，而不是堆数值
每场战斗的紧张感来自"我认出了他要出什么招"。敌人起手统一 0.45–0.65 秒前摇，配合体色变红，给玩家可读的信号。
PILLAR 02
形态即战术
剑打节奏、斧打结构、枪打距离。三把武器共享同一条破防条，所以它们互相配合，而不是互相替代。
PILLAR 03
会下沉的大陆
裂片停留过久会开始坠落。探索被时间推着走，玩家必须在"多搜一个巢"和"活着离开"之间做选择。

选题理由：三维像素是目前独立团队性价比最高的差异化美术——体素建模成本低、无贴图管线、光照与阴影天然出效果，同时"低分辨率"本身就能掩盖资产精度不足。玩法上避开开放世界，用小而密的裂片换取密度而非面积。

02世界观：崩响之后

大陆"厄兰"在一次被称为崩响的事件中裂成数百块浮空残片。每块残片都被冻结在崩塌前一瞬的地貌里——所以你会在同一片区域里看到春天的花和秋天的落叶同时存在。

玩家是提灯者，身上带着唯一还能工作的"锚"：一根能把人钉在裂片上的青铜桩。当裂片之间的引力错位时，只有锚能让提灯者跨过裂痕。

侵蚀体是裂片自我修补时排出的残渣，它们本能地想把一切"修回原样"——包括把活人碾成建材。这就是敌人存在的理由，也是它们死后留下"碎晶"的原因。

叙事的表达方式是环境，不是过场动画：一块裂片里出现的建筑残骸、被冻结在半空的雨、墙上重复的同一幅壁画，都在说明"这里曾经完整过"。

03核心循环

30 秒
穿过一段有垂直落差的地形，识别一处侵蚀巢（有音效与地面裂纹提示）。
45 秒
遭遇战：读招 → 弹反 / 翻滚 → 重击堆破防 → 破防窗口内爆发。
15 秒
收取碎晶与"裂片记忆"，决定继续深入还是回锚点。
3 分钟
回到锚点，花碎晶点亮一个烙印节点，解锁一段新的位移能力或武器招式。

关键设计：敌人不刷新。这让"清空一片区域"成为真实成就，也避免玩家在原地刷资源，把节奏锁在推进上。碎晶的主要来源是巢穴与裂片事件，而非击杀数。

04战斗系统

三层资源

  • 生命：100 点。不自动回复，只能靠锚点或消耗品。归零后回到最近锚点，敌人已击杀的状态保留。
  • 体力：100 点，停手 0.55 秒后以 26/秒 回复。所有进攻与防御都吃体力，它才是真正的节奏刹车。
  • 破防条：挂在敌人身上。满值即进入 2.2 秒硬直，期间受到双倍伤害。这是战斗的唯一"得分方式"。

v1.1 起移除了怒气系统：大招不再靠资源攒满释放，而是改为格斗游戏式的指令技（见下文）。删掉一层资源后，战斗决策全部回到"读招、站位、出刀"三件事上。

每把武器的动作设计

三把武器不是同一套挥砍换了数值，而是三套独立的关节关键帧。摆动轴、出手方向、身体重心全部不同，玩家闭着眼也能靠动作认出武器。

动作系统用关节关键帧驱动：每个动作是一串 {进度, 关节角度}，字段覆盖右臂三轴、左臂、上身俯仰/扭腰、整体前倾、手臂前后位移、武器前后位移、离地高度。命中判定与关键帧对齐（hitAt），所以"看到打到"就是"真的打到"。挥击窗口会沿武器方向生成短命高光，连成挥砍拖影——在 384×216 的渲染分辨率下，这是让人看清高速动作的关键。

指令技系统

每把武器有 10 式指令技，用方向序列 + 攻击键释放：窗口 0.8 秒内依次输入方向（WASD 或方向键），再点左键（轻）或右键（重）。输入序列实时显示在左上角 HUD，命中时高亮技能名——玩家不需要背表， UI 就是表。

三条设计原则：① 武器性格决定动作语法——剑多段轻盈、斧只有两段但每段沉重、枪全是单点穿透加超长位移，所以同一套指令在三把武器上打出完全不同的节奏。② 突进技走胶囊判定——前冲类技能记录"起点→当前位置"线段做命中检测，冲过敌人不会 miss，一路上全都扫到。③ 终极技是指令的终点而非资源的起点——不需要攒任何条，任何玩家在任何一个安静瞬间都能放出来，但放之前依然要读场上局势。

④ 释放瞬间自动锁怪——搓招的方向键会带动角色转身，玩家经常在"输入方向"和"敌人方向"之间被撕开，技能放空。释放指令技的瞬间，角色强制转向 15 米内最近的存活敌人（多目标取最近，无目标则保持当前朝向），并在目标脚下亮起一个金环作为锁定反馈。普通攻击不受影响，保持原有的转向手感。

⑤ 左右横断系补齐方向库——v1.6 起每把武器新增 3 式左右连招：→←轻（交叉横斩两段，前冲贴脸）、←→轻（后撤拉开距离再反手横割，攻防一体）、←←重（大范围横断两击，扇形 260°–310° 扫侧翼）。上下系负责"纵深"（前冲突进 / 跳砸地裂），左右系负责"宽度"（横扫侧翼的包围圈）——配合自动锁怪，搓招本身就是一次转向与走位决策。

闪避的战术价值

闪避不是"躲完继续打"，它本身就是进攻选择。两条独立机制：

机制触发回报
完美闪避翻滚起手 0.16 秒内被攻击锁定（敌我前摇对上的瞬间）0.3 倍慢放 0.3 秒 · 体力 +25 · 1.5 秒反击窗口（下次攻击与技能 ×1.6 伤、×1.5 破防）
穿袭翻滚途中切过敌人（1.25 米 + 身位）固定伤害 10 + 关卡×2 · 体力 +8 · 敌人直接进入硬直

设计意图：把"回避"从成本中心变成收益中心。完美闪避的窗口比完美弹反（0.22 秒）更短但更容易预判——玩家读的是敌人的起手，不是自己的帧表，所以它是弹之外的第二条进攻线。

敌人协同：包围而不是堆怪

  • 攻击令牌：同时允许出手的敌人上限为 1 + min(3, ⌊关卡/2⌋)。抢不到令牌的敌人不发呆，而是绕到侧翼游走，等前排收招再补位——玩家看到的是一圈伺机而动的包围网，而不是全部贴脸。
  • 收招惩罚：玩家挥空（whiff）或重击后摇期间，全队提速 65% 压上。这是对"乱按"最直接的反馈。
  • 包抄走位：近战在攻击距离 1.45 倍处环绕玩家，每 1.1–2.5 秒换一次方向，不会永远从同一个角度切入。
  • 远程独立节奏：弩手走自己的射击带逻辑，不受令牌限制（上限放宽到 +1），保证远程压力持续存在。

掉落与计分

  • 露珠（生命 +24）与真气（体力 +40）：统领必掉 1 个，守卫 40%，其他 16%。生命已满时露珠自动转化为真气，不浪费。
  • 计分：史莱姆 15 / 弩手 30 / 守卫 40 / 统领 150。分数只进不退，是给反复重开玩家的一個外部目标。
  • 结算面板：过关时展示本关击杀、用时、累计分数、累计击杀、倒下次数。

05探索结构

每块裂片是一张 40–60 米 的独立地图，穿行时间设计在 40–70 秒。不做无缝大世界，因为那会让内容密度被稀释，也会把美术成本推到小团队撑不住的位置。

  • 锚点：每片 1 个，兼作存档、治疗与快速移动。点亮需要先清掉附近的巢。
  • 垂直性：地形按 0.5 米体素台阶抬升，玩家永远能看到"上面还有一层"，解锁二段跳后可以回访旧裂片开辟新路径。
  • 下沉事件：进入裂片 6 分钟后开始抖动，9 分钟后强制坠落。造成的不是死亡，而是"抢不到的东西"——这比扣血更有压力。
  • 可选挑战：无伤巢穴、限时裂片、静默路线（不惊动任何敌人）。奖励是烙印点而非数值装备。
设计原则：每一块裂片都必须有一个一眼能记住的轮廓。玩家回忆起地图时，应该记得"那座斜着的塔"，而不是"那片森林"。

06成长：烙印树

不做装备数值成长，做动词扩展。三条分支，共 18 个节点，全部是"多一个选择"而不是"多 10 点攻击"。

剑术支
延长弹反窗口（0.22→0.28 秒）、连段第三段附加破防、完美弹反后 1 秒内重击不耗体力。
体术支
翻滚距离 +25%、格挡体力消耗减半、二段跳、空中翻滚。
碎境支
滑翔、锚点弹射（把自己钉到远处岩壁）、裂片坠落时短暂悬停、看穿巢穴位置。

所有节点都需要 1 个"裂片记忆"，记忆只能通过探索与挑战获得。这样"探索"和"变强"是同一件事。

07美术与技术规格

三维像素是怎么做出来的

不是"低多边形"，而是低分辨率 + 体素形体的组合：几何全部由方块搭建，材质是无贴图的硬边 Lambert，最终画面渲染到 384×216 的缓冲，再用最近邻放大铺满屏幕。像素颗粒来自渲染分辨率，不来自贴图，所以相机推近时不会有"贴图糊掉"的问题。

可读性底线

低分辨率最大的坑是"看不清"。三条硬规则：敌人轮廓色永远比地表亮 2 级；起手必变色（红）；玩家角色永远有暖色披风作为定位锚点。UI 用 HTML 层叠渲染，不参与像素化，保证中文可读。

移动端触屏适配

同一份构建同时跑桌面与手机：触屏设备自动加载虚拟输入层，键鼠玩家无感。移动操作用左下虚拟摇杆——360° 模拟量拨动，倾斜越满跑得越快；指令技的搓招在触屏上不缩水——摇杆越过死区时按主轴方向（上/下/左/右）向同一条指令缓冲入队，与键盘 keydown 完全同路，回中再拨即可搓出 ↑↑ / ↑↓ / ↓↑ / ↓↓。

布局
左下虚拟摇杆（模拟量移动 + 四象限搓招，环上四向刻度搓招时高亮），右下动作键：轻击 / 重击 / 闪避 / 格挡 / 换武 / 治疗；竖屏显示旋转提示，建议横屏
摇杆量化
死区 30%；取主轴方向入队（斜拨也归到上下左右），连续同向不重复计数，回中再拨才算第二次输入；单拨一次 + 攻击 = 普通攻击，不误触技能
终极技
␣↓↓ + 右键 → 闪避键 + ↓↓ + 重击（HUD 提示随端切换文案）
输入链路
摇杆象限切换 = pushDir（与键盘同源）；动作键 = tryAttack / doDodge / startGuard / swapWeapon / tryHeal；moveDir 摇杆优先，moveScale 输出模拟量速度
防误触
touch-action:none + 全局 touchmove/gesturestart/dblclick 拦截，禁下拉刷新与双指缩放；按钮与摇杆各自只跟踪一个触点，支持多指同按（摇杆按住 + 连点攻击）
适配细节
viewport-fit=cover + env(safe-area-inset) 避让刘海/小黑条；窄屏 HUD 与摇杆缩放；全屏按钮；iOS AudioContext 手势内创建并 resume；失焦自动松开摇杆
性能
384×216 渲染缓冲 + 像素比 1，触屏 GPU 负载与桌面一致；逻辑帧与渲染帧解耦（dt 截断 0.05s）

小地图：透明全图雷达

被包围或敌人被地形/树木挡住时，玩家第一诉求是"敌人在哪"。右上角一块圆形透明小地图解决追踪问题：整张 46×46 场地一次映射，所有存活怪物实时标点，不用切视角、不用记路。设计上刻意做"淡"——半透明底盘 + 细描边，不抢主画面注意力。

映射
世界坐标线性映射到画布（-23~23 → 0~132px），圆形裁剪；画布缓冲跟随 CSS 尺寸（桌面 132 / 手机 104），元素按比例缩放
怪物标点
按类型分色：史莱姆红 / 守卫橙 / 弩手黄 / 统领紫（统领点更大）；死亡敌人立即消失；点带同色微光，低分辨率下也认得出
当前目标
与 HUD 目标框同一套逻辑（9 米内最近）：脚下脉冲金环，被锁定的是谁一眼可见
玩家标记
金色三角指向当前朝向，地图上方 = 世界 -Z，与主画面方位一致
锚点
三个治疗锚点画青色小点，撤退路线有参照
性能
2D 画布每帧重绘，单帧约 20 次 arc 填充；不参与 WebGL 像素化管线，中文可读性不受影响

音频：程序化配乐与战吼

配乐与音效全部用 Web Audio 程序化生成，不依赖任何外部音频文件——离线可跑、包体为零、随构建一起分发。音乐是一台小型步进音序器：A 小调 Am–F–C–G 四小节循环，贝斯走根音、琶音走三和弦、噪声合成鼓组，全部经低通滤波后并入音乐总线。

冒险主题
108 BPM，中速推进：底鼓落 1/3 拍、军鼓落 2/4 拍、8 分琶音铺开史诗感，铺底和弦每小节起一次
BOSS 主题
152 BPM，四踩底鼓 + 16 分踩镲 + 八度跳动贝斯，更快更密；切入瞬间叠一段上扫 stinger，压迫感拉满
切换逻辑
每帧检测场上是否有存活 boss：有 → 切 BOSS 主题；boss 倒下 → 回到冒险主题；在同一小节边界直接切换，强调"紧张起来"的突变
战吼
释放指令技瞬间合成一声"嘿 / 哈"——锯齿波声源 + 双共振峰带通 + 噪声气息，离线合成、不依赖语音库；终极技固定喊"哈"
技能名呼喊
离线共振峰语音合成：每个技能名手工标注拼音（含声调），用 Web Audio 自建「普通话音节合成器」逐音节念出，完全不依赖系统 TTS 与任何中文语音包，离线必定出声。v1.8 重构清晰度：改用加性共振峰（AudioBuffer 逐采样渲染）替代旧版高 Q 窄带通——元音由多次谐波 × 共振峰包络合成，饱满自然；声母按成阻部位着色噪声 + F2 过渡（区分 b/d/g 的关键）；输出经去齿音 + 2.5kHz 存在感提升 + 限幅主链，相对 BGM 更突出、不爆音（机器人腔，非自然人声）
音量与开关
音乐走独立总线，HUD 左上"♪ 音乐"可一键静音 / 恢复；音效与战吼直连输出，不受音乐静音影响

BOSS：碎境魔将

每逢 第 5 / 10 / 15… 裂片，场上会额外降临一只碎境魔将：2.25 倍体型、深红身躯、双角加冠，血量约为普通统领的 3 倍，并继承震击与召唤。它是该裂片的强制击杀目标——不清掉它就无法净化裂片。魔将存活期间配乐自动切到 BOSS 主题，玩家不看血条也能从音乐里听出"还没打完"。

10风险与验证点

风险表现对策
低分辨率下目标识别困难玩家找不到敌人或被围攻时无法判断优先级轮廓色阶 + 起手变色 + 透明小地图全图标点（怪物分色 + 目标金环，实测 13 项像素级自检全绿）
三武器学习成本过高玩家只用剑，其余两把沦为摆设用敌人结构强制（守卫必须靠斧破防，悬丝者必须靠枪够到）
弹反手感依赖输入延迟0.22 秒窗口在 60ms 延迟下变成 0.16 秒垂直切片先测手感；预留"输入缓冲 0.1 秒"
体素地形手工成本每块裂片地形制作 3–5 天模块化地形块 + 程序化生成 + 手工修饰
多段技能被击退打断多段技能前几段把敌人推出后续判定范围多段技能单独压击退（0.06–0.4）；单发技能保持 0.75–1.0
突进技冲过敌人导致 miss惊雷刺前冲 5.4 米，敌人在 2.2 米时被穿过，扇形判定丢失前冲类技能改用「起点→当前位置」胶囊判定（实测修复，18 项数值全绿）
搓招转向导致技能放空输入 ↑↑ 时角色朝屏幕上方转身，敌人在侧面或背后，方向技打空释放瞬间自动锁怪：强制转向 15 米内最近敌人，目标脚下金环反馈（实测修复，背对/侧对/多目标 7 项全绿）
指令技误触移动中的方向输入被累积成指令，玩家普攻时莫名放技能输入窗口压到 0.8 秒、同方向不重复计数（keydown 非 repeat / 十字键按下一次才入队）
触屏搓招精度摇杆快速拨动（↑↑）时第二击落在窗口外，或斜拨被量化丢方向0.8 秒窗口对快速回拨绰绰有余；死区 30% 防抖， quadrant 切换才入队，单拨不误触普攻
